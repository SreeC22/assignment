ChatGPT's job-scan agent told me a role was "posted August 4, verified live." The canonical record said December 2025. This is the verification step it skipped, running for real: paste any Lever, Ashby, or Greenhouse posting URL plus the date the agent claimed, and get a receipt straight from the job board's own record.

Verification receipt · freshness

How it works: the page detects the ATS from the URL and fetches the board's own public record (Lever createdAt, Ashby publishedAt, Greenhouse first_published), then compares it to the claimed date with a 7-day tolerance. Match → VERIFIED with source and timestamp. Mismatch → CONFLICT: the claim is not asserted, and in the proposed ChatGPT integration the recommendation is held for the user. Fetch impossible → honest UNVERIFIED, never fake confidence. A companion UI mock shows how these receipts render inside a ChatGPT scan card.
